# 100 Days of Code — Python 🐍

My journey through Angela Yu's *100 Days of Code* course. Each folder is a
day's project — games, OOP exercises and small apps. Pure Python standard
library, no pip installs required.

## 📂 Projects

| Folder | What it is |
|--------|------------|
| `pong/` | Classic Pong — turtle graphics, classes, collision detection, scoring |
| `snake_game/` | Snake — OOP with `Snake`, `Food` and `Scoreboard` classes |
| `coffee_machine_oop/` | Coffee machine simulator, object-oriented refactor (menu, makers, money) |
| `quiz-game-start/` | Quiz app — questions from `data.py`, OOP quiz brain |
| `day_17/` | Quiz game — OOP |
| `day_18/` | Turtle drawing: shapes, spirograph, random walk, Hirst-style painting |
| `day_19/` | Turtle race & state management |
| `pretty_table/` | PrettyTable practice |

## 🚀 Run a project locally

```bash
git clone https://github.com/bmalvo/100_days_of_code.git
cd 100_days_of_code/pong
python main.py
```

Requires **Python 3** — standard library only.
